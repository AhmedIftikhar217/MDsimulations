# mdsimulation website

Static site for the draft paper "Hidden sources of irreproducibility in simulations of hydrophobic assembly", deployed at https://mdsimulation.vercel.app.

- `index.html`: the whole page, with the interactive chart's data inlined
- `paper/`: the draft manuscript as a PDF
- `figures/`: figures from the paper and molecular renderings, as WebP
- `data/`: Supplementary Data 1, per-run values for all ten runs
- `fonts/`: Archivo and Source Serif 4 (SIL Open Font License), self-hosted

This branch holds only the website. The simulation code is on `main`.
